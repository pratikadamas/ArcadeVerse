User Privacy & Transparency

Privacy Policy

ArcadeVerse is committed to strict privacy standards: zero tracking cookies, zero surveillance analytics, and complete local user sovereignty.

Zero Tracking Cookies • 100% Client-Side Storage • Open Source Privacy
01

Privacy Philosophy & Core Commitment

ArcadeVerse was engineered from inception on the principle of data minimization. We believe you should be able to play retro games, learn programming, and participate in open-source hackathons without being tracked across the web.

We do not collect, sell, rent, or monetize your personal data. There are no commercial advertisements, tracking pixels, behavioral telemetry scripts, or marketing trackers integrated into ArcadeVerse.

02

Local Storage Usage & Data Inventory

ArcadeVerse uses your browser's standard HTML5 LocalStorage API solely to persist your client-side preferences and gameplay state between sessions. This data never leaves your browser:

Storage Key Purpose Data Type Retention
arcadeverse_theme_mode Persists your Dark or Light UI color theme preference String ('dark' / 'light') Persistent
arcadeverse_favorite_games Stores your bookmarked favorite game IDs JSON Array of strings Persistent
arcadeverse_daily_quest Tracks daily quest completion and consecutive streak days JSON Object Persistent
arcadeverse_recently_played_v2 Saves up to 6 recently played titles for Quick Resume JSON Array of objects Persistent (FIFO)
arcadeverse_sound_settings Audio synthesizer volume level and mute/unmute state JSON Object Persistent
arcadeverse_a11y_prefs Accessibility toggles (reduced motion, high contrast, text size) JSON Object Persistent
arcadeverse_game_ratings Records your 5-star ratings for community mini-games JSON Object Persistent
arcadeverse_contributors_cache_v2_* Caches GitHub REST contributors data to prevent 60/hr API rate limits JSON Object with timestamp 30-minute TTL
arcadeverse_playlists Custom user playlists containing ordered game collections JSON Array of objects Persistent
arcadeverse_catalog_view Catalog display layout preference ('grid' or 'list' view) String ('grid' / 'list') Persistent
arcadeverse_backup_snapshot_* Atomic rollback backup snapshots captured prior to JSON save imports JSON Object Transient (Atomic commit / rollback)
arcadeverse_game_saves_* Namespaced save game files, states, and persistent level progression JSON / Serialized string Persistent

03

External Network Requests & CDNs

To provide real-time rankings and typography, ArcadeVerse communicates with the following external endpoints:

  • GitHub REST API (api.github.com): Reads public contributor and commit statistics for the ArcadeVerse repository to display the Hall of Fame. These are public, unauthenticated read-only requests.
  • Google Fonts (fonts.googleapis.com & fonts.gstatic.com): Delivers web fonts (Cambria Math, Permanent Marker, JetBrains Mono).
  • Lucide Icons CDN (unpkg.com/lucide): Delivers lightweight SVG iconography for the interface.
04

Zero Cookies Guarantee

ArcadeVerse sets zero HTTP cookies. We do not use first-party or third-party cookies, tracking beacons, fingerprinting algorithms, or session recording tools (such as Hotjar or FullStory).

05

Children's Privacy Protection

ArcadeVerse is an educational programming and gaming station accessible to individuals of all ages. Because we do not collect personal identifying information (PII), we do not knowingly solicit or store data from children under the age of 13 in compliance with COPPA and global privacy laws.

06

Open-Source Code Auditability

Every line of code powering ArcadeVerse is publicly auditable on GitHub. You can inspect all client-side scripts, network calls, and data handling in the public repository at any time:
https://github.com/DebasmitaBose0/ArcadeVerse

07

Policy Modifications & Contact

We may update this Privacy Policy periodically to reflect enhancements to our open-source platform. Any changes will be committed directly to git with a clear revision date.

For privacy inquiries or technical questions, please open an issue on our GitHub repository or contact the project administration team.
