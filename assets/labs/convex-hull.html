Use in a game

Load assets/js/convex-hull-collision.js and use ArcadeVerse.physics. Prepare local vertices once. Re-prepare when they rotate or deform. Pass B’s translation relative to A, and add the result’s MTV to B to resolve penetration.

const a = ArcadeVerse.physics.prepareConvexPolygon(pointsA);
const b = ArcadeVerse.physics.prepareConvexPolygon(pointsB);
const result = ArcadeVerse.physics.collideConvexPolygons(a, b, bx - ax, by - ay);
if (result.intersects && !result.touching) {
  bx += result.mtvX;
  by += result.mtvY;
}

Boundary contact intersects with zero depth. Hulls with fewer than three vertices have no solid area. minimumBoundingBox returns local corners and area for a prepared polygon.
