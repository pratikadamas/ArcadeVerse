Audio Compatibility & Architectural Integration

ArcadeVerse embeds games inside isolated <iframe> elements to guarantee security and prevent DOM collisions. Master audio preferences are communicated to compatible games via three non-invasive integration layers without breaking game-specific volume sliders or unsupported titles:

Integration Channel Mechanism Compatibility Status
Cross-Frame Messaging postMessage({ type: 'arcadeverse:sound-toggle', enabled, muted }, '*') Fully Supported
Parent Audio Manager window.parent.ArcadePreferences.isMuted() / window.parent.ArcadeSoundEngine Fully Supported
Namespaced Storage localStorage.getItem('arcadeverse:preferences:muted') Fully Supported
Isolated Web Audio Games creating local AudioContext without checking parent or postMessage Independent (Preserved)
